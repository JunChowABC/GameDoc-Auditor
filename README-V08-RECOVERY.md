## V0.8 功能复原范围

- 大于 12 份文档时默认开启聚焦选中关系。
- 文档聚焦：中心文档 + 最多 8 份关联文档，分布于两侧。
- 单条关系：仅显示两份关联文档与完整连线，并显示双方引用证据。
- 完整关系总览：采用节点碰撞检查的自动网格布局，可缩放、平移及拖动节点；拖动禁止覆盖其他节点。
- 顶部「查看文档」选择框，切换当前聚焦文档。
- SVG/JSON 导出、按关系筛选、回到原文定位功能继续保留。
- 节点长标题根据中英文宽度估算缩略，避免覆盖相邻卡片。

## 本地运行

安装 Python 3 后，在项目目录运行：

```bash
python -m http.server 8010 --directory dist
```

浏览器打开 `http://localhost:8010`。默认无需 API Key、后端服务或 AI。

## 测试

需要 Node.js 18 或更新版本：
